## Ideas

- [ ] When openening an editor as a guest we should check if there is a default eclipse editor registered for this file/extension, otherwise a system editor will pop-up. But it can't read oct:// files. If no editor registered, open with default eclipse text editor.

- [ ] Would be nice to have a context menu entry in package/project explorer view for quick share of files. Right now we can only share the whole project

- [ ] Add a possibility to ignore file from share using e.g. .gitignore or a list of patterns. Also well known ignores like `bin`, `target`, `DS_Store` or `node_modules` should be considered. Add a preference that is on by default.
